 # 🌱 Proof-of-Tree

A Clarity smart contract that rewards people for planting trees.  
Users submit proof (e.g. photo hash on IPFS), and the admin grants tokens as eco-rewards.

---

## ✨ Features
- 🌍 Users submit planting proof.
- 🎁 Admin issues green tokens.
- 💰 Users check balances on-chain.
